# Початок роботи

[English](GETTING_STARTED.md) · [Русский](GETTING_STARTED.ru.md)

1. Завантажте `LocalAgentAIStation-<версія>-Setup-x64.exe` з
   [Releases](https://github.com/Wave-is/laas/releases), випуск із позначкою **Pre-release**.
2. Запустіть інсталятор, виберіть мову та встановіть застосунок. Потрібна Windows
   10/11 x64. Python уже включено. Ранній випуск поки не має сертифіката підпису коду.
3. Відкрийте **Local Agent AI Station** через «Пуск» або ярлик робочого столу.
   На головній панелі — модель, агенти й виявлені GPU. Під час першого запуску
   компоненти автоматично не вмикаються. Інтерфейс застосунку поки російською.
4. На сторінці **Агенты** виберіть встановлений інтерфейс і натисніть **Запустить**.
   **Установить** відкриває офіційні релізи агента. Встановіть його окремо, потім
   натисніть **Повторить обнаружение**. **Остановить** завершує примірник, запущений Station.
5. Для локальної моделі задайте шляхи llama.cpp/llama-swap і профіль у **Модели**.
   Приклади — [профілі моделей](MODEL_PROFILES.md) та `docs/examples`.
   Ваги, облікові записи й передплати сторонніх агентів до інсталятора не входять.
6. У **Настройках** за бажанням увімкніть автозапуск із Windows. Компоненти
   вибираються окремо: локальні служби → готовність моделі → інтерфейси агентів.
   Задайте затримку, виберіть потрібне й збережіть. Параметр `--no-startup`
   пропускає автоматичний запуск компонентів для відновлення роботи.

**Служби:** додайте локальний процес із командою або адресу віддаленого ComfyUI/HTTP
worker. Віддалений сервіс можна перевірити та відкрити; Station не запускає інший ПК.
Опитування можна вимкнути. Є [інструкція з прикладами](SERVICES_GUIDE_RU.md).

**Трей:** права кнопка відкриває керування моделями, агентами та GPU. Хрестик вікна
зазвичай приховує панель у трей; для завершення виберіть **Выход**. Вигляд значка
та два канали показників налаштовуються окремо.

**Режими GPU:** моніторинг працює без привілейованої служби. Для перемикання потрібні
сумісні NVIDIA та [окремий helper](GPU_MODE_HELPER.md). Від'єднайте монітори від карт,
що переводяться в TCC. Інсталятор не встановлює цю службу; перевірка повного циклу
роботи встановленого нового helper ще не завершена.

## Шляхи, оновлення та видалення

| Що | Стандартний шлях |
|---|---|
| Програма | `%ProgramFiles%\Local Agent AI Station` |
| Налаштування, профілі, журнали | `%LOCALAPPDATA%\LocalAgentAIStation` |
| «Пуск» і робочий стіл | Звичайні ярлики поточного користувача |

Для оновлення завершіть Station та запустіть новий інсталятор поверх поточної версії.
Налаштування збережуться. Оновлення поки встановлюються вручну.
Видалення: **Параметри → Програми → Інстальовані програми → Local Agent AI Station**.
Видаляються файли програми, її ярлики й запис автозапуску; дані, моделі та зовнішні
агенти залишаються. Перед поверненням до старої версії скопіюйте папку даних.

Відкрийте журнали із застосунку або створіть діагностичний звіт:

```powershell
& "$env:ProgramFiles\Local Agent AI Station\LocalAgentAIStation.exe" --doctor --output "$env:TEMP\station-doctor.json"
```

Звіт може містити локальні шляхи, ідентифікатори GPU й відомості про налаштування
агентів. Перевірте та знеособте його перед додаванням до issue. Не публікуйте API-ключі.
