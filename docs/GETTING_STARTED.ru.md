# Начало работы

[English](GETTING_STARTED.md) · [Українська](GETTING_STARTED.uk.md)

1. Скачайте `LocalAgentAIStation-<версия>-Setup-x64.exe` из
   [Releases](https://github.com/Wave-is/laas/releases), выпуск с отметкой **Pre-release**.
2. Запустите установщик, выберите язык и установите приложение. Нужна Windows 10/11
   x64. Python уже включён. У раннего выпуска пока нет сертификата подписи кода.
3. Откройте **Local Agent AI Station** через «Пуск» или ярлык рабочего стола.
   На дашборде — модель, агенты и обнаруженные GPU. При первом запуске компоненты
   автоматически не включаются.
4. На странице **Агенты** выберите установленный интерфейс и нажмите **Запустить**.
   **Установить** открывает официальные релизы агента. Установите его отдельно,
   затем нажмите **Найти агенты заново**. **Остановить** завершает экземпляр,
   запущенный самой Station.
5. Для локальной модели в **Настройки → Папки и сервер моделей** укажите папку движка
   (где лежат llama-swap.exe и llama-server.exe) и папку моделей, затем профиль в **Модели**.
   Примеры — [профили моделей](MODEL_PROFILES.md) и `docs/examples`.
   Веса, аккаунты и подписки сторонних агентов в установщик не входят.
6. В **Настройках** при желании включите автозагрузку с Windows. Запуск компонентов
   выбирается отдельно: локальные службы → сервер моделей и модель → агенты.
   Задайте задержку, отметьте нужное и сохраните. Для восстановления запуск с
   `--no-startup` пропускает автоматический запуск компонентов.

**Службы:** добавьте локальный процесс с командой или адрес удалённого ComfyUI/HTTP
worker. Удалённый сервис можно проверить и открыть; удалённый ПК Station не запускает.
Опрос можно выключить. Есть [инструкция с примерами](SERVICES_GUIDE_RU.md).

**Трей:** правая кнопка открывает управление моделями, агентами и GPU. Крестик окна
обычно скрывает панель в трей; для завершения выберите **Выход**. В настройках
меняются вид значка и два канала показателей.

**Режимы GPU:** мониторинг работает без привилегированной службы. Для переключения
нужны совместимые NVIDIA и [отдельный helper](GPU_MODE_HELPER.md). Отсоедините мониторы
от карт, переводимых в TCC. Установщик не ставит эту службу; проверка полного цикла
работы установленного нового helper ещё не завершена.

## Пути, обновление и удаление

| Что | Стандартный путь |
|---|---|
| Программа | `%ProgramFiles%\Local Agent AI Station` |
| Настройки, профили, журналы | `%LOCALAPPDATA%\LocalAgentAIStation` |
| «Пуск» и рабочий стол | Обычные ярлыки текущего пользователя |

Для обновления завершите Station и запустите новый установщик поверх текущей версии.
Настройки сохранятся. Обновления пока устанавливаются вручную.
Удаление: **Параметры → Приложения → Установленные приложения → Local Agent AI Station**.
Удаляются файлы программы, её ярлыки и запись автозагрузки; данные, модели и внешние
агенты остаются. Перед возвратом на старую версию сделайте копию папки данных.

Откройте журналы из приложения либо создайте диагностический отчёт:

```powershell
& "$env:ProgramFiles\Local Agent AI Station\LocalAgentAIStation.exe" --doctor --output "$env:TEMP\station-doctor.json"
```

В отчёте бывают локальные пути, идентификаторы GPU и сведения о настройках агентов.
Проверьте и обезличьте его перед отправкой в issue. Не публикуйте API-ключи.
