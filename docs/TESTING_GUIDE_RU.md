Проверка Local Agent AI Station

Начните с Qwen Code Desktop. Первые шаги занимают примерно 15–20 минут,
не считая установки агента и загрузки модели. Проверяйте по одному действию.

1. ЗАПУСК
Откройте ярлык «Local Agent AI Station» на рабочем столе. Откройте его ещё раз:
должно показаться существующее окно, без второй копии панели.
Ожидается: приложение готово, модель сама не запускается.

2. ОБОРУДОВАНИЕ
Откройте «Оборудование». На вашем ПК должны отображаться две NVIDIA RTX A5000
и Intel UHD 770. Температура, загрузка и память NVIDIA обновляются; неизвестные
показатели Intel обозначаются прочерком. На другом ПК число устройств будет другим.
Для первого прохода оставьте профиль «Текущая конфигурация».
Ожидается: список соответствует вашему ПК, интерфейс продолжает отвечать.

3. АГЕНТЫ И УСТАНОВКА
Откройте «Агенты». У отсутствующего агента нажмите «Установить»:
браузер должен открыть официальный GitHub Releases этого продукта.
Для Qwen выбирайте именно Qwen Code Desktop и установщик Windows x64.
После установки нажмите «Повторить обнаружение». Если installer изменил PATH,
может понадобиться перезапуск Station. Для нестандартной папки есть настройки Runtime.
Ожидается: установленный компонент получает соответствующий статус.
Установка других агентов для первого теста Qwen не обязательна.

4. ЗАПУСК МОДЕЛИ
При открытии «Станция» сразу показывает сервер, загруженную модель, интерфейс
агента и карточки всех GPU. Статус модели должен соответствовать ответу backend.
На «Станция» выберите основной профиль Qwen3.8 27B и нажмите «Запустить».
Дождитесь сообщения о готовности. Во время загрузки попробуйте открыть
«Оборудование»: панель должна оставаться отзывчивой, использование VRAM вырастет.
Ожидается: модель считается загруженной после ответа сервера.
Запишите время от нажатия до готовности; большой первый запуск может занять минуты.

5. ВСТРОЕННАЯ ПРОВЕРКА
На «Модели» выберите тот же профиль и нажмите «Проверить модель».
Ожидается: успешны текст, потоковый ответ, два потока и вызов инструмента;
для vision-профиля также проверяется изображение. Отчёт сохраняется в qualification
в каталоге данных приложения. Короткая проверка не испытывает весь максимальный контекст.

6. ДИАЛОГ В QWEN DESKTOP
На «Станция» выберите агент Qwen Code и интерфейс Qwen Code Desktop → «Открыть».
Если показаны изменения подключения модели, просмотрите их и примените:
Station сохранит backup и проверит подключение перед открытием агента.
Введите в Qwen: «Ответь ровно STATION_USER_OK». Ожидается именно этот ответ.
При выборе интерфейса GPU-профиль и загруженная модель должны остаться прежними.

7. РАБОТА С ФАЙЛОМ
Используйте отдельную папку для проверки. На этом ПК подготовлена:
%LOCALAPPDATA%\LocalAgentAIStation\workspace\station-user-test
Откройте её в агенте. В ней находятся input.txt и README.txt с инструкцией.
Попросите: «Прочитай input.txt через инструмент чтения файла. Создай result.txt,
скопировав содержимое input.txt без изменений. Затем прочитай result.txt и сообщи,
совпадает ли содержимое». Ожидается: файл существует и в точности совпадает с input.txt.
Проверяйте сам файл, а не только сообщение агента об успехе.

8. СМЕНА АГЕНТА И МОДЕЛИ
После установки Pi/OpenClaw выберите их интерфейс на «Станция» и повторите шаги
6–7 с той же моделью. Переключение агента не должно перезагружать модель.
Затем завершите задачу, выберите другую доступную модель и запустите её.
Ожидается: старая модель выгружена, новая отвечает, информация на панели обновлена.
OpenClaw Local Terminal и его Gateway проверяйте по очереди: один каталог состояния
не может одновременно принадлежать двум этим процессам.

9. ОСТАНОВКА И ПОВТОРНЫЙ ЗАПУСК
На «Станция» остановите выбранный интерфейс кнопкой «Остановить», затем
нажмите «Выгрузить» у модели. Ожидается: собственный процесс агента завершается,
внизу панели нет загруженных моделей, VRAM освобождается. Другие приложения работают.
Запустите модель и агента снова: последовательность должна повториться без ручного
завершения процессов. Закрытие панели крестиком обычно сворачивает её в трей.

ПРОВЕРКА ТРЕЯ
Правой кнопкой по значку откройте меню: модель, агенты, GPU, пресеты и службы.
Если Windows спрятала значок, раскройте область скрытых значков. Те же команды
есть в «Быстрое меню» внутри Station. Проверьте запуск и выгрузку модели из меню.
У GPU-профиля с реальными изменениями открывается подтверждение: названия карт,
текущий и целевой режим, предупреждение об отключении мониторов от карт для TCC.
«Отмена» и крестик ничего не применяют. «Больше не показывать» сохраняется только
при нажатии «Переключить»; следующие выборы GPU-профиля выполняются без этого
окна. Вернуть его можно в «Настройки» → «Управление режимами GPU» →
«Вернуть подтверждение GPU». Проверка дисплеев действует и с отключённым окном.
Если режимы уже совпадают, подтверждения нет: появляется сообщение, что изменение
не требуется. У неподдерживаемых карт выводится предупреждение о пропуске.
Проверка меню не требует применения новых режимов. Выход оставляет процессы работать:
сначала остановите агент/модель, если хотите полностью завершить локальную работу.

В «Настройках» выберите две иконки. Для каждой задайте GPU, показатель цифрами,
показатель заливкой и цвет. Например: температура цифрами, нагрузка фоном.
Нажмите «Применить к трею», перезапустите панель и проверьте сохранение.
Также проверьте одну плитку с двумя показателями, светлую тему, максимум/среднее
и логотип. У отсутствующего GPU должен быть прочерк, а не выдуманный ноль.

10. ДЛИТЕЛЬНЫЙ ПРОГОН
После успешных шагов 1–9 дайте Qwen задачу на 30–60 минут в отдельном тестовом
проекте: создать небольшую утилиту, запустить её, исправить найденные ошибки.
Периодически смотрите температуру, память и отзывчивость Station.
Отмечайте зависания, обрывы ответа, неожиданные перезагрузки модели и ошибки инструмента.

ПЕРЕКЛЮЧЕНИЕ WDDM/TCC — ОТДЕЛЬНЫЙ ЭТАП
Новая GPU-служба пока не установлена и её проверка на этом ПК не завершена.
Сейчас можно просматривать план GPU. Проверку реального переключения выполняем
после установки LocalAgentGpuModeHelper и отдельно от агентских задач.
Удаление прежней службы не устанавливает новую и не меняет текущие режимы GPU.

COMFYUI И ДРУГИЕ СЕРВИСЫ
На странице «Службы» нажмите «Добавить сервис» или «Как пользоваться».
Для уже работающего сервера введите название, выберите ComfyUI либо HTTP-сервис,
укажите адрес с портом. Новая запись по умолчанию не опрашивается автоматически.
После сохранения проверьте карточку, нажмите «Проверить» в удобное время, затем
откройте адрес. Для локального запуска задайте программу и параметры в форме.
Подробные примеры находятся во встроенной инструкции и docs/SERVICES_GUIDE_RU.md.
Регистрация карточки не подключает агент к генерации автоматически: агенту нужен
свой инструмент/MCP, использующий этот адрес. Само приложение хранит подключение,
проверяет доступность и управляет только локальными процессами, запущенными им.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
Запишите время, выбранные модель/агент/интерфейс, точные шаги и текст ошибки.
Журналы: «Службы» → «Открыть журналы». Каталог данных этого ПК:
%LOCALAPPDATA%\LocalAgentAIStation. Для разбора достаточно назвать неудачный шаг
и что произошло; исходный текст ошибки полезнее предположения о причине.
# Запуск агентов и автозагрузка

В «Агенты» выберите интерфейс в карточке (например Qwen Code Desktop) и нажмите
«Запустить». Когда Station запустит процесс, станет доступна «Остановить».
Перед остановкой завершите текущую задачу агента. Если агент открыт отдельно,
Station не считает его своим процессом и не завершает по имени.

В «Настройки → Запуск Station и компонентов»:

1. «Запускать Station при входе в Windows» сразу добавляет/убирает ярлык текущего
   пользователя. Это запуск после входа в учётную запись, без прав администратора.
2. Выберите, открывать ли Station свёрнутой в трей.
3. При необходимости включите автоматический запуск компонентов, выберите модель,
   Desktop/терминалы/другие интерфейсы агентов и локальные службы. Укажите задержку.
4. Нажмите «Сохранить запуск». Выбор применяется при следующем запуске Station.
5. Для проверки завершите Station через «Быстрое меню → Выход из Station», затем
   откройте ярлык снова. Закрытие крестиком обычно только скрывает её в трей.
6. Во время задержки доступна отмена. «Результат запуска» в настройках показывает
   выполненные действия и ошибки. При ошибке окно разворачивается из трея.

Пример: модель Qwen + Qwen Code Desktop + задержка 10 секунд. Перед первым
автоматическим запуском один раз загрузите эту модель, запустите Desktop вручную
и подтвердите подключение модели, если Station показывает изменение настроек.
Далее модель загружается до открытия агента. Режимы GPU автоматически не меняются.
Локальные службы запускаются первыми; удалённые уже работают на своём компьютере.
Если выключить остановку последовательности при ошибке, остальные выбранные
компоненты продолжат запускаться. Отмена не завершает уже работающие процессы.

Для диагностики без запуска компонентов используйте `LocalAgentAIStation.exe
--no-startup --data-dir "путь к данным"`. `--doctor` также не запускает компоненты.
Проверка Windows-ярлыка в разработке выполняется в изолированной папке; реальный
вход/выход Windows на рабочем ПК во время этой проверки не выполнялся.
