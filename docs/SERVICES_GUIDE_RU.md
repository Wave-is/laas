СЕРВИСЫ В STATION: С ЧЕГО НАЧАТЬ

Этот раздел хранит подключения к ComfyUI, image worker и другим сервисам.
Один сервис может использоваться с разными агентами. Выбор агента не запускает
и не останавливает его автоматически.

СЕРВИС УЖЕ РАБОТАЕТ НА ДРУГОМ КОМПЬЮТЕРЕ

1. Нажмите «Добавить сервис» и задайте понятное название.
2. Выберите «ComfyUI» для его прямого интерфейса или «Image worker / HTTP-сервис»
   для отдельного сервера с собственным API.
3. Выберите «Уже работает / другой компьютер», вставьте адрес с портом.
4. Нажмите «Сохранить». Если компьютер занят, оставьте автопроверки выключенными.
5. Когда можно проверять, нажмите «Проверить» на карточке. Это одна проверка
   доступности, без постановки изображений в очередь и без загрузки моделей.
6. Нажмите «Открыть адрес», чтобы перейти к сервису, либо «Скопировать адрес»,
   чтобы передать его инструменту генерации вашего агента.

Пример прямого ComfyUI:
Название: ComfyUI на втором ПК
Тип: ComfyUI
Адрес: http://192.168.1.10:8188
Station сама использует /system_stats для проверки. Замените пример своим адресом.

Пример отдельного image worker:
Название: Сервер изображений
Тип: Image worker / HTTP-сервис
Адрес: http://192.168.1.10:8000
Адрес проверки: http://192.168.1.10:8000/health
Порт 8000 и путь /health — пример. Возьмите их из настроек вашего сервера.
Image worker может предоставлять только API, без страницы генерации в браузере.

У удалённой карточки нет команд запуска и остановки процесса. Ими управляют
на том компьютере, где установлен сервис. «Убрать из Station» удаляет только
сохранённое подключение; сервер и его файлы остаются на месте.

КАК ПОЛУЧИТЬ ИЗОБРАЖЕНИЕ

В интерфейсе ComfyUI откройте свой рабочий workflow, выберите установленную там
модель, введите описание и отправьте workflow на выполнение. Например:
«Небольшой деревянный дом у озера, утренний туман, мягкий свет».
Результат появится в ComfyUI. Подключение в Station отвечает за адрес и доступность;
workflow и модели хранятся на сервере ComfyUI.

Для генерации из Qwen, Hermes, Pi или другого агента нужен его инструмент или
MCP-подключение к ComfyUI / image worker. Укажите в нём скопированный адрес.
Регистрация карточки сама по себе не добавляет агенту такой инструмент.

ЗАПУСК НА ЭТОМ КОМПЬЮТЕРЕ

1. Установите сам сервис и убедитесь, что знаете его программу и параметры.
2. В форме выберите «Запускать на этом компьютере».
3. Выберите файл программы. Для Python это python.exe из окружения сервиса.
4. Укажите рабочую папку и параметры: каждый аргумент на отдельной строке,
   без добавления кавычек, даже если в пути есть пробелы.
5. Сохраните. Нажмите «Запустить» на карточке, затем «Проверить».
6. Для завершения нажмите «Остановить». Station завершает только свой процесс.
   Если сервис уже запущен отдельно, добавьте его как «Уже работает».

Пример параметров для установленной копии ComfyUI:
C:\ComfyUI\main.py
--listen
127.0.0.1

Замените пути реальными. У portable-сборок они могут отличаться. Журнал появляется
после запуска через Station и открывается кнопкой «Журнал» на карточке.
Изменять настройки или убирать работающую локальную карточку следует после остановки.

ЧТО ОЗНАЧАЕТ СТАТУС

«Проверки выключены» — Station не опрашивает адрес автоматически. Можно выполнить
одну ручную проверку. Её время и результат видны на карточке.
«Доступен» — сервер ответил на проверку; это не обещание успешной генерации.
«Нет подключения» — сервер не ответил: проверьте сеть/VPN, адрес, порт; возможно,
он временно занят. Это не команда перезапустить другой компьютер.
«Требует внимания» — сервер ответил ошибкой или вместо ComfyUI вернул другой API.
«Процесс запущен» — локальный процесс существует, готовность HTTP ещё не подтверждена.
«Остановлен» — Station не видит принадлежащего ей локального процесса.

Изменить адрес, название или автопроверки: «Настроить» на карточке. Новое подключение
по умолчанию сохраняется без автопроверок. При включении интервал — 30 секунд.

Описание API ComfyUI: https://docs.comfy.org/development/comfyui-server/comms_routes
