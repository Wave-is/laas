# Аппаратные профили

`config/hardware_profiles.yaml` задаёт роли graphics/compute/mixed/excluded/auto
по устойчивому UUID NVIDIA или DXGI LUID. Число GPU не фиксировано. included_devices
и excluded_devices ограничивают выбор; отсутствующий явный UUID не подменяется
другим устройством. general_policy задаёт общую политику для текущего оборудования.

WDDM/TCC меняются отдельным действием, после просмотра плана. Изменение frontend
не меняет аппаратные режимы. На дисплейной карте TCC отклоняется. AMD/Intel
перечисляются, но переключение WDDM/TCC для них не поддерживается.

`prefer_p2p` допускает fallback с предупреждением; `require_p2p` запрещает запуск
модели без подтверждённой связи между выбранными устройствами. `require_nvlink`
тоже строгое требование. Для обычной работы эти строгие флаги не нужны.

Свободная VRAM и ограничения проверяются на выбранных устройствах. Объём памяти
интегрированного адаптера не прибавляется к памяти CUDA. Неизвестное значение
показывается как неизвестное. Проверка модели на реальном backend обязательна для
подтверждения её практической пригодности; см. VALIDATION.md.
