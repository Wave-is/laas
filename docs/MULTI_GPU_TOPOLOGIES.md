# Топология нескольких GPU

Station раздельно показывает физический NVLink, доступность CUDA P2P и факт
измерения трафика. Наличие моста не доказывает, что текущий запрос использует его.
Скорость и трафик NVLink в этой версии не измеряются.

NVIDIA UUID используется вместо предположения о постоянном индексе GPU0/GPU1.
Матрицы `nvidia-smi topo -p2p r/w` проверяются в обе стороны. Связная цепочка
GPU не считается полной P2P-группой: для clique нужна связь каждой пары.
Ошибки topo возвращают неизвестную топологию, а не демонстрационную станцию.

Тяжёлая модель может запускаться на WDDM и без P2P, если её профиль не требует
P2P строго, хватает памяти и backend поддерживает fallback. Такая конфигурация
получает предупреждение и требует настоящей проверки модели.

Автотесты покрывают 0/1/2/3/4/8 GPU и неодинаковые объёмы памяти. Реальные
испытания выполнены на двух A5000 и встроенном Intel UHD 770; см. VALIDATION.md.
