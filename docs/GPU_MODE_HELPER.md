# GPU Mode Helper 3.0

`LocalAgentGpuModeHelper` — отдельная Windows-служба для переключения
поддерживающих TCC устройств NVIDIA. Основная Station работает от пользователя.
Исходники: `src/services/LocalAgentGpuModeHelper.cs`. .NET Framework входит в Windows.

## Граница полномочий

- Только локальный named pipe `\\.\pipe\LocalAgentGpuModeHelper`.
- Разрешены указанный при установке пользователь, SYSTEM и администраторы.
  Сетевой вход явно запрещён ACL.
- Операции: GetHardwareStatus, GetDriverModes, ApplyDriverModePlan, CancelSwitch.
- План содержит только полный NVIDIA UUID и WDDM/TCC/UNCHANGED; ограничен 64 GPU.
- Нет аргументов executable, script, command или произвольных путей.
- Запускается только `%SystemRoot%\System32\nvidia-smi.exe` после проверки
  Authenticode. Используется обычный `-dm`, принудительный `-fdm` не используется.
- Ограничены размер запроса, время чтения и число клиентов; переключения сериализованы.
- Изменение только pending не считается живым успешным переключением:
  сообщается RebootRequired. Station независимо повторяет аппаратный опрос.

## Установка

Сначала собрать `src/services/build_helper.ps1`. Затем из административного
PowerShell выполнить `src/services/install_helper.ps1 -AllowedUserSid <SID>`.
SID обычного пользователя можно узнать заранее командой `whoami /user`.
Кнопка установки в Station передаёт SID вызывающего пользователя до повышения прав.
Это важно, если административные учётные данные принадлежат другому пользователю.

Служба копируется в `%ProgramFiles%\LocalAgentAIStation`, работает от SYSTEM,
запускается автоматически. Каталог защищён от записи обычными пользователями;
ссылки и reparse points в путях установки отклоняются. Старый EXE при обновлении
сохраняется с суффиксом `.rollback`. Это резервная копия, а не автоматический откат.

Установка новой службы в текущей сессии ещё не выполнена; см. VALIDATION.md.
Старая HermesGpuModeService не удаляется автоматически и не входит в новую сборку.

## Эксплуатация и удаление

Аппаратное переключение останавливает только backend, которым владеет Station.
Активный агент сначала нужно завершить. Приложение не убивает процессы по имени.
Если сервер внешний, операция отклоняется. После изменения режимов модель не
запускается самопроизвольно. Частичный отказ содержит план возврата предыдущих режимов.

`src/services/uninstall_helper.ps1` от администратора останавливает и снимает
регистрацию только LocalAgentGpuModeHelper. Файлы приложения, GPU-режимы,
конфигурации и исходная служба Hermes не затрагиваются.
