СЕРВІСИ В STATION: З ЧОГО ПОЧАТИ

Цей розділ зберігає підключення до ComfyUI, image worker та інших сервісів.
Один сервіс можна використовувати з різними агентами. Вибір агента не запускає
і не зупиняє його автоматично.

СЕРВІС УЖЕ ПРАЦЮЄ НА ІНШОМУ КОМП'ЮТЕРІ

1. Натисніть «Додати сервіс» і вкажіть зрозумілу назву.
2. Виберіть «ComfyUI» для його власного інтерфейсу або «Image worker / HTTP-сервіс»
   для окремого сервера з власним API.
3. Виберіть «Уже працює / інший комп'ютер», вставте адресу з портом.
4. Натисніть «Зберегти». Якщо комп'ютер зайнятий, залиште автоперевірки вимкненими.
5. Коли можна перевіряти, натисніть «Перевірити» на картці. Це одна перевірка
   доступності, без додавання зображень у чергу та без завантаження моделей.
6. Натисніть «Відкрити адресу», щоб перейти до сервісу, або «Скопіювати адресу»,
   щоб передати її інструменту генерації вашого агента.

Приклад прямого ComfyUI:
Назва: ComfyUI на другому ПК
Тип: ComfyUI
Адреса: http://192.168.1.10:8188
Station сама використовує /system_stats для перевірки. Замініть приклад своєю адресою.

Приклад окремого image worker:
Назва: Сервер зображень
Тип: Image worker / HTTP-сервіс
Адреса: http://192.168.1.10:8000
Адреса перевірки: http://192.168.1.10:8000/health
Порт 8000 і шлях /health — приклад. Візьміть їх із налаштувань вашого сервера.
Image worker може надавати лише API, без сторінки генерації в браузері.

Віддалена картка не має команд запуску та зупинки процесу. Ними керують
на тому комп'ютері, де встановлено сервіс. «Прибрати зі Station» видаляє лише
збережене підключення; сервер і його файли залишаються на місці.

ЯК ОТРИМАТИ ЗОБРАЖЕННЯ

В інтерфейсі ComfyUI відкрийте свій робочий workflow, виберіть встановлену там
модель, введіть опис і надішліть workflow на виконання. Наприклад:
«Невеликий дерев'яний будинок біля озера, ранковий туман, м'яке світло».
Результат з'явиться в ComfyUI. Підключення в Station відповідає за адресу та доступність;
workflow і моделі зберігаються на сервері ComfyUI.

Для генерації з Qwen, Hermes, Pi або іншого агента потрібен його інструмент або
MCP-підключення до ComfyUI / image worker. Вкажіть у ньому скопійовану адресу.
Реєстрація картки сама по собі не додає агенту такого інструмента.

ЗАПУСК НА ЦЬОМУ КОМП'ЮТЕРІ

1. Встановіть сам сервіс і переконайтеся, що знаєте його програму та параметри.
2. У формі виберіть «Запускати на цьому комп'ютері».
3. Виберіть файл програми. Для Python це python.exe з оточення сервісу.
4. Вкажіть робочу папку та параметри: кожен аргумент на окремому рядку,
   без додавання лапок, навіть якщо в шляху є пробіли.
5. Збережіть. Натисніть «Запустити» на картці, потім «Перевірити».
6. Для завершення натисніть «Зупинити». Station завершує лише свій процес.
   Якщо сервіс уже запущено окремо, додайте його як «Уже працює».

Приклад параметрів для встановленої копії ComfyUI:
C:\ComfyUI\main.py
--listen
127.0.0.1

Замініть шляхи реальними. У portable-збірках вони можуть відрізнятися. Журнал з'являється
після запуску через Station і відкривається кнопкою «Журнал» на картці.
Змінювати налаштування або прибирати працюючу локальну картку слід після зупинки.

ЩО ОЗНАЧАЄ СТАТУС

«Перевірки вимкнено» — Station не опитує адресу автоматично. Можна виконати
одну ручну перевірку. Її час і результат видно на картці.
«Доступний» — сервер відповів на перевірку; це не гарантія успішної генерації.
«Немає підключення» — сервер не відповів: перевірте мережу/VPN, адресу, порт; можливо,
він тимчасово зайнятий. Це не команда перезапустити інший комп'ютер.
«Потребує уваги» — сервер відповів помилкою або замість ComfyUI повернув інший API.
«Процес запущено» — локальний процес існує, готовність HTTP ще не підтверджено.
«Зупинено» — Station не бачить локального процесу, що їй належить.

Змінити адресу, назву або автоперевірки: «Налаштувати» на картці. Нове підключення
за замовчуванням зберігається без автоперевірок. Якщо їх увімкнути, інтервал — 30 секунд.

Опис API ComfyUI: https://docs.comfy.org/development/comfyui-server/comms_routes
