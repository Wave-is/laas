# Пресеты станции

`config/station_presets.yaml` содержит редактируемые комбинации:
GPU-профиль, модель, основной runtime, предпочтительный frontend и дополнительные
фоновые runtime. Пресет не превращает эти компоненты в неразделимую связку.

Без auto_start_model профиль модели только выбирается, а не объявляется загруженным.
Без auto_start_agents интерфейс не запускается. Применение пресета показывает его
содержимое; отдельное переключение frontend не перезагружает backend и GPU.

Отсутствующий runtime/frontend не устанавливается незаметно. Фоновый Gateway
может требовать собственной настройки Hermes и не проверялся отправкой сообщений
в сторонние сервисы. Не включайте его автоматически до такой настройки.

Унаследованные поля fallback/warmup сохранены в схеме для совместимости данных,
но автоматический fallback модели и отдельный warmup workflow в этой версии
не реализованы. Не полагайтесь на эти поля при эксплуатации.
