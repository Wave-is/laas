# Постоянный знак Local Agent AI Station

Знак — геометрическая A из двух направлений, мятного и голубого, на тёмной плитке.
Он принадлежит самой Station и не использует логотипы поддерживаемых агентов.
Лицензия ресурсов — MIT, как у проекта.

- `assets/brand/station.svg` — вектор для GitHub, документации и дальнейших материалов.
- `assets/brand/station.png` — PNG 512×512 для аватара проекта.
- `assets/brand/station.ico` — Windows EXE, ярлык и заголовок окна, размеры 16–256.
- `src/branding.py` — единая геометрия, `tools/build_brand_assets.py` — воспроизводимый экспорт.

Не заменять знак при каждом выпуске. Телеметрия в трее меняется независимо от
бренда: пользователь может выбрать цифры/заливку или этот постоянный логотип.
Маленький индикатор у логотипа трея показывает доступность backend, а не загрузку модели.

Одноразовое восстановление старых настроек не относится к пользовательским
сценариям бренда/панели. Оно оставлено в техническом CLI `main.pyw --migrate`
с просмотром плана; `--apply` выполняет перенос с резервными копиями.
